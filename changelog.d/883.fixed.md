**Per-runtime dbt artifact isolation.** Build evidence records sanitized `artifact_producer` metadata and reads `run_results.json` and `manifest.json` from the directory the build wrote. The policy is runtime isolation. A clean shared `target/` is reused. A cross-runtime snapshot path collision isolates or refuses without deleting caller-owned artifacts, and `dbt build` receives that directory as `--target-path`. A foreign invocation id cannot come back as a successful completion.
